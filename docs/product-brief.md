# 太白说 产品简介

## 一、从 Vibe Coding 到 Lounge Coding

### Vibe Coding（1.0）

**Vibe Coding** = 和 AI 聊天写代码

- 用自然语言描述需求
- AI（如 Claude Code、Cursor）自动生成代码、执行命令
- 通过对话迭代优化

这是 2026 年 AI 时代的新型开发方式。

### 痛点

但 Vibe Coding 还是要**打字**。聊一天下来，手腕照样酸。

而且只能在电脑前用，出门了就断了。

### Lounge Coding（2.0）

**Lounge Coding** = 躺平式 AI 编程

躺平，但高效。

| 对比 | Vibe Coding | Lounge Coding |
|------|-------------|---------------|
| 输入方式 | 打字 | 语音 |
| 姿势 | 坐着 | 躺平 |
| 场所 | 电脑前 | 随时随地 |

**太白说** = Lounge Coding 标准装备 = 程序员躺平神器

---

## 二、太白说是什么？

把 Vibe Coding 升级成 Lounge Coding 的工具。

让你躺平也能高效编程：

- 🗣️ 手机语音输入，内容同步到电脑
- 🛋️ 不用碰键盘，躺平也能写代码
- 📱 手机变触控板，操控电脑
- 🌐 支持局域网或公网部署，随时随地都能用
- ⚡ **不用装 App，浏览器打开就用，1 秒进入工作状态**

---

## 三、核心功能

| 功能 | 说明 |
|------|------|
| 📱 **语音转文字** | 借助手机输入法（推荐豆包）的语音识别，说话即上屏 |
| 🖱️ **全屏触控板** | 手机变身触控板，躺着控制鼠标 |
| 🖥️ **远程模式** | 手机查看电脑屏幕，触控操作，在外也能干活 |
| ⌨️ **热键控制** | 支持 Ctrl+C、Escape 等快捷键，长按连续发送 |
| 🚀 **快捷操作** | Tab 切换、继续、回滚、编译、提交等一键操作 |
| 🔧 **正则替换** | 自定义关键词替换规则 |
| ⚙️ **设定中心** | 自定义命令和常用语 |

## 四、使用场景

### 场景 A：日常开发（本地模式）

**一天的 Lounge Coding 工作流：**

```
09:00  躺在椅子上，语音说"我要实现一个用户营销功能"
09:05  AI 问需求细节，语音讨论，敲定方案
09:30  语音说"开始实现"，AI 写代码，你躺着看
10:00  语音说"跑一下测试"，看结果，有 bug
10:05  语音说"第三个测试失败了，帮我修一下"
10:20  测试全过，语音说"提交"
10:21  继续躺着，下一个任务...
18:00  下班回家 🎉
```

**全程躺平，全程高效。**

### 场景 B：紧急救火（远程模式）

**下班路上的惊魂一刻：**

```
19:30  地铁上，挤得要死
19:35  老板打电话："线上挂了！紧急修复！"
19:36  掏出手机，打开太白说，进入远程模式
19:37  手机上看到电脑屏幕，定位到问题
19:40  语音说"把这个判断条件改一下"，AI 修复
19:45  语音说"部署到生产"
19:50  老板："好了，辛苦了"
19:51  收起手机，继续挤地铁，开心到家 🏠
```

**没背电脑，照样救火。**

### 场景 C：出差酒店

**没带电脑也能干活：**

```
出差只带了换洗衣服
酒店里需要改点东西
打开手机浏览器，进入太白说
远程连上公司电脑
语音操作，搞定收工
```

### 场景 D：身体抗议

**腱鞘炎程序员の自救：**

```
手腕已经开始疼了
医生说少打字
但代码还得写
用太白说，语音代替打字
手腕得救，工作继续
```

### 场景 E：带娃遛狗

**一心二用の极致：**

```
娃在旁边玩 / 狗在前面跑
手里拿着手机
语音说"帮我把那个接口改一下"
AI 改完了
娃没丢，狗没跑，代码写完了
```

## 五、目标用户

1. **AI 编程用户** - 用 Claude Code、Cursor 等工具 Vibe Coding
2. **手腕不好的程序员** - 长期打字导致腱鞘炎/手腕酸痛
3. **效率工具爱好者** - 追求更高效的工作方式
4. **远程办公/居家工作者** - 想躺着也能干活
5. **内容创作者** - 语音写作比打字更流畅

## 六、核心卖点

1. **语音代替打字** - 从 Vibe Coding 升级到 Lounge Coding

3. **随时随地** - 局域网或公网部署，在外也能继续
4. **专为 AI 编程优化** - 快捷按钮适配 Claude Code 工作流

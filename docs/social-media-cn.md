### 标题
AI 编程进化论：从 Vibe Coding 到 Lounge Coding

### 摘要

本文介绍 Lounge Coding 的概念和实践，以及开源工具太白说的使用。

### 正文

#### 引言

2026 年，Vibe Coding（和 AI 聊天写代码）已成为开发者的日常。但在实践中，我发现了两个核心痛点，并探索出一种新的工作方式：Lounge Coding。

#### Vibe Coding 的局限

**痛点一：输入方式**

虽然 AI 承担了大部分编码工作，但开发者仍需通过键盘与 AI 交互。长时间打字带来的手腕疲劳问题并未解决。

**痛点二：场所限制**

Vibe Coding 依赖电脑终端，开发者必须在电脑前才能工作。这限制了工作的灵活性。

#### Lounge Coding：下一代 AI 编程范式

**Lounge Coding** 是对 Vibe Coding 的升级，核心特征：

| 维度 | Vibe Coding | Lounge Coding |
|------|-------------|---------------|
| 输入 | 键盘打字 | 语音输入 |
| 姿势 | 坐姿 | 任意姿势 |
| 场所 | 电脑前 | 随时随地 |

#### 工具实现：太白说

太白说是一个开源的 Lounge Coding 工具：

**架构：**
- 服务端：Python + Flask，运行在开发机上
- 客户端：Web 页面，手机浏览器访问
- 通信：HTTP + WebSocket

**核心功能：**
1. 语音输入同步：借助手机输入法的语音识别
2. 触控板模式：手机模拟鼠标操作
3. 远程模式：实时查看电脑屏幕并操控
4. 快捷操作：适配 Claude Code 等 AI 工具

**部署方式：**
- 局域网：开箱即用
- 公网：配合反向代理，支持随时随地访问

I've been doing Vibe Coding (chatting with AI to write code) for a while, but noticed two pain points:

- Phone becomes touchpad
- Remote mode: see your screen on phone, control from anywhere
- No app install needed, just open browser
